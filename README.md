# Yapo 智利分类广告数据集样本

<h2>包含 4,619 条记录的样本数据集</h2>

<a href="https://www.bright.cn/">
    <img src="https://github.com/bright-cn/Yapo-Chile-marketplace-dataset-samples/blob/main/datasets-image.png" alt="Bright Data 数据集" />

此 **Yapo 智利市场广告数据集样本**包含 **4,619 条记录**，并通过 **Bright Data API** 提取。

## 数据点

| 字段名称 | 描述 |
|------------|-------------|
| `title` | 广告标题，简要概述产品或服务。 |
| `description` | 广告内容的详细描述，包括重要功能和详细信息。 |
| `seller_name` | 发布广告的个人或实体名称。 |
| `root_category_id` | 广告根类别的唯一标识符。 |
| `root_category_name` | 根类别名称，表示广告的一般分类。 |
| `parent_category_id` | 父类别的唯一标识符，用于提供广告的子分类。 |
| `parent_category_name` | 父类别名称，用于更具体地对广告进行分类。 |
| `active` | 指示广告当前是否有效的布尔值。 |
| `city` | 广告所在或相关的城市。 |
| `region` | 广告所涉及的智利地区。 |
| `date_creation` | 广告的创建日期，用于判断其新近程度。 |
| `phone_image` | 广告中所用手机的图片（如适用）。 |
| `images` | 与广告相关的图片，用于提供视觉信息。 |
| `price` | 所宣传商品或服务的价格。 |
| `publisher_type` | 发布者类型，例如个人或企业。 |
| `ad_type` | 广告类型，例如出售或出租。 |
| `estate_type` | 房地产类型（如适用），例如公寓或独栋住宅。 |
| `rooms` | 所宣传房产的房间数量。 |
| `bathrooms` | 所宣传房产的卫生间数量。 |
| `total_square` | 所宣传房产的总面积（平方英尺）。 |
| `expenses` | 与广告相关的额外费用（如有）。 |
| `parking_lots` | 与广告相关的可用停车位信息。 |
| `other_amenities` | 产品或服务提供的其他配套设施。 |
| `car_type` | 汽车类型（如果广告与车辆相关）。 |
| `mileage` | 所宣传车辆的行驶里程。 |
| `fuel` | 广告中车辆所使用的燃料类型。 |
| `gearbox` | 所宣传车辆的变速箱类型。 |
| `condition` | 所宣传商品的状况，即全新或二手。 |
| `gender` | 卖家的性别（如有注明）。 |
| `main_phone` | 广告的主要联系电话号码。 |
| `phones` | 用于联系的其他电话号码。 |
| `main_email` | 广告的主要联系电子邮件地址。 |
| `emails` | 用于联系广告发布者的其他电子邮件地址。 |
| `id` | 广告的唯一标识符。 |
| `url` | 在线广告的 URL 链接。 |
| `seller_id` | 广告卖家的唯一标识符。 |
| `currency` | 广告中标价所使用的货币。 |
| `built_square` | 所宣传房产的建筑面积（平方英尺）。 |
| `destaque` | 广告是否被推荐或突出显示的信息。 |


## 使用场景

### 1. 市场趋势分析
分析数据以识别智利市场的新兴趋势，帮助企业适应消费者需求。

### 2. 房地产洞察
利用数据集深入了解智利房地产市场，帮助房地产投资者做出明智决策。

### 3. 消费者行为研究
根据广告互动情况研究消费者行为模式，制定有针对性的营销策略。
